# ATLAS Viewer Release: v11.5.4.464-W41

This release adds a number of usability improvements across the viewer, plus bug fixes for Stream Recorder.

<!-- more -->

!!! info "Evaluation Build Notice"
    This release is provided as an evaluation build, offering early access to a set of completed fixes and features ahead of a full production release. Evaluation builds are intended for validation and early feedback, and while the included changes are functionally complete, there may still be known limitations or issues that are addressed before the final release. We encourage users to report any problems or feedback encountered during evaluation, as this helps ensure the highest quality for the full release.

## New Features

### Search in the Function Browser
The Function Browser now has a search box that narrows the list of functions as you type, matching on function and parameter names. This makes large function libraries much easier to navigate than scrolling through the full list.

### Tooltips on Truncated Summary Column Headers (#140709022)
Column headers in the Summary display now show a tooltip with the full header text, so truncated headers can be read without resizing the column.

### Waveform Legend Strikethrough Visible at Small Font Sizes (#53669)
The strikethrough used in the Waveform legend to mark hidden parameters is now drawn at a fixed thickness, so it remains visible at font sizes below 10pt.

### Monospaced Font for Binary Values in the Waveform Legend (#57074)
Binary-format values in the Waveform legend are now shown in a monospaced font, making individual bits easier to read and compare.

## Bug Fixes

### Lap Time Functions Returning the Wrong Lap After a Lap Reset (#60185)
Fixed an issue where the `LapTime` and `CurrentLapNumber` processors returned the wrong lap time when the lap number reset during a session, for example after a car was powered off during a red flag. Lap times for repeated lap numbers are now taken from the correct lap.

### Crash and Workbook Corruption When Creating a 23rd Set
Fixed a crash that occurred when creating a new Set after deleting one of 22 existing Sets, which could also corrupt the workbook. ATLAS now reuses freed Set numbers and limits a workbook to 22 Sets.

### Stream Recorder Not Stopping with Two or More Sessions Running
Fixed an issue where Stream Recorder could intermittently fail to stop when multiple sessions were running.

### Stream Recorder Configuration Changes Not Applied in Auto Record
Fixed an issue where changes made to a Stream Recorder configuration (Tools > Options > Stream Recorder) were not applied to recorders already set to auto record until auto record was toggled off and on again. Changes now take effect on the next recording.
