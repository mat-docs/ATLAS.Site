# ATLAS Viewer Release: vTBC-R04

This release introduces a preview FFT display and an updated to the Web Browser display, and a range of usability refinements to the Function Browser, Parameter Browser, Session Browser and Waveform legend. It also fixes crashes, display issues after set or session changes, and Stream Recorder reliability and performance problems.

<!-- more -->

## New Features

### FFT Display (Preview) (#52534, #52826, #53867, #54676, #54728, #54742, #56125, #56574, #56793, #56811, #56889)

A new FFT display shows the frequency spectrum of a single parameter, so you can analyse vibration, suspension, sensor noise and similar phenomena without exporting data to external tools. The display is a preview feature: enable it under **Tools → Options → General → Preview Features** (*Allow FFT Display (Preview Feature)*) and restart ATLAS, then add it from **File → New → Display** or the toolbar.

### Web Browser Display Update (#57454)

The Web Browser display has moved from the legacy Internet Explorer 11 control to Microsoft WebView2. Modern websites, including those with video and complex layouts, now load and render correctly. The WebView2 Runtime must be installed; it is usually included with Windows 11. On some systems, your IT administrator may need to install it.

### PCU-700 Firmware Update and Separate Product and Custom XML (#60429, #60432, #60436)

ATLAS now ships with an updated PCU-700 firmware DLL, resolving mismatches between the PCU-700 display in ATLAS and the physical dash. PCU dash definitions are now split between a Product XML and a Custom XML, so your own firmware versions can be added and selected from a two-level dropdown without modifying files that ship with ATLAS. The location of custom firmware DLLs is configurable in the Custom XML, which is validated when loaded.

### Record VPS Sessions in ATLAS

Stream Recorder has a new option to record Virtual Parameter Service (VPS) sessions. Virtual parameters calculated by ATLAS can now be stored and reviewed later, for example to debug calculations that feed your models.

### Stream Recorder Performance with Multiple Recorders (#60584)

Reduced memory allocations when refreshing parameters, so ATLAS stays responsive when viewing live data from two or more Stream Recorders at the same time.

### USB Logger Performance Improvements

Optimised how the USB Logger processes files, cutting processing time by roughly 45% for both SQLite (SSN2) and SQL Race output. Typical times compared with v11.5.4.464:

| File | Output | v11.5.4.464 | This release |
|------|--------|-------------|--------------|
| 91,438 KB (10 laps) | SQLite (SSN2) | 4 mins 10 secs | 2 mins 21 secs |
| 91,438 KB (10 laps) | SQL Race | 5 mins 20 secs | 2 mins 40 secs |
| 1,488,806 KB (36 laps) | SQLite (SSN2) | 19 mins 48 secs | 11 mins 8 secs |
| 1,488,806 KB (36 laps) | SQL Race | 19 mins 23 secs | 10 mins 42 secs |

### Search in the Function Browser (#54660, #55188, #56277)

The Function Browser now has a search box that filters the function list as you type, matching on function and parameter names. This makes it much quicker to find a function in large libraries, where scrolling was previously the only option.

### Parameter Browser: Up and Down Keys Follow the Sorted Order (#60394, #56866)

The Up and Down keys in the Parameter Browser now step through parameters in the order they are currently sorted, rather than the original unsorted list.

### Session Browser: Sort Recording Date as a Date (#52394, #54841, #56399, #60545)

The *Date of recording* column in the Session Browser now sorts chronologically rather than as text, and handles day/month/year date formats correctly.

### Session Browser: Export Session Remembers the Last Folder (#52168)

Export Session now opens in the folder you last exported to, and cancelling the folder dialog no longer shows an error.

### Tooltips on Truncated Summary Column Headers

Column headers in the Summary display now show a tooltip with the full header text, so you can read headers that are truncated when a column is narrow and cut off by the edge of the display.

### Waveform Legend Improvements (#53669, #57074)

The strikethrough used to mark hidden items now stays visible at small font sizes, where it previously disappeared below 10pt. Binary values are now shown in a monospaced font so the digits line up and are easier to compare.

## Bug Fixes

### Import/Export Configuration Exports Unselected Items (#57478)

Fixed an issue where exporting a configuration included items that had been unchecked, so each exported profile contained the combined selection of all profiles. Only the items you select are now exported.

### ATLAS Freezes in Distance Mode After a Lap Trigger (#57385)

Fixed an issue where ATLAS could freeze in distance mode after a lap trigger.

### Samples in Error Not Processed Correctly (#6582)

Fixed an issue where samples were flagged as in error using the wrong error bit definition and the converted rather than the raw value. Error status now follows the parameter's error bitmask on the raw value.

### Crash and Workbook Corruption When Creating a 23rd Set (#60470)

Fixed an issue where deleting a set and then creating a new one could assign it set number 23, causing ATLAS to crash and the workbook to become corrupted. Deleted set numbers are now reused, and the number of sets is limited to 22.

### Incorrect Lap Times After a Lap Number Reset (#60179, #60185)

Fixed an issue where the `LapTime` and `CurrentLapNumber` processors could return the wrong lap when the lap number reset during a session, for example when a car is powered off during a red flag. Lap times for laps after a reset now come from the correct lap rather than the earlier lap with the same number.

### Very Slow Offloads Caused by Lap Trigger Issues (#60590)

Fixed an issue where repeated attempts to add an out lap during an offload could make the offload very slow.

### Bar Display Duplicated After Changing Sets or Loading a Session (#60761, #60802)

Fixed an issue where a Bar Display was duplicated when you changed set or loaded a new session, leaving the original display showing incorrect values.

### Event Display Parameter Blank After Reloading a Session

Fixed an issue where the parameter shown in an Event Display went blank after a session was loaded and reloaded.

### Numeric Display Not Updating on Null Values and Showing the Wrong Data Status

Fixed an issue where the Numeric display did not blank when moved to a point with no data, and where its per-sample data status indicator was always shown as `=` instead of reflecting the real status.

### Numeric Display Blank for Session Details Parameters (#61108)

Fixed an issue, found in v11.5.4.464-W41, where the Numeric display showed no values for parameters in the Session Details group, for both live and historic data. Values for these parameters now display correctly.

### Waveform Only Showing the First Segment of RTA Sessions (#60644)

Fixed an issue where Waveform displays for sessions loaded through an RTA Service Connection showed only the first section of telemetry, with the rest of the session blank.

### Alarm Events Stored in the Session

Fixed an issue where alarms were stored as session events, which could fail when ATLAS had only read access to a SQL Server FILESTREAM folder. Alarm events are now held as transient events in memory.

### Stream Recorder Not Stopping with Two or More Sessions

Fixed an intermittent issue where Stream Recorder would not stop when more than one session was running.

### Stream Recorder Configuration Changes Not Applied in Auto Record

Fixed an issue where changes made to a Stream Recorder configuration were not applied to recorders set to auto record until auto record was switched off and on again. Configuration changes now take effect on those recorders straight away.

### Stream Recorder Not Always Starting with a Session Identifier Pattern

Fixed an intermittent issue where Stream Recorder did not always start recording when a Session Identifier pattern was configured.

### Crash When Starting the Built-in Memory Profiler

Fixed a crash when starting the memory profiler from **Tools → Performance Profilers**, which occurred when ATLAS was installed under Program Files.

### Crash When Double-Clicking the Close Button on Parameter Properties (#54110)

Fixed a crash that occurred when double-clicking the close button on the Parameter Properties window.

### Ctrl+L in the Function Editor Opens the Session Browser (#56865, #56868)

Fixed an issue where pressing Ctrl+L in the Function Editor cut the current line instead of opening the Session Browser. The shortcut now works as it does elsewhere in ATLAS.

### Client API: CompositeDataRequestSignal Could Not Be Sent

Fixed an issue where a `CompositeDataRequestSignal` could not be sent to the SignalBus by Client API plugins.
