# ATLAS Viewer Release: v11.5.4.464-W41

This release adds a search box to the Function Browser and refines the Summary and Waveform displays, alongside fixes for a crash when creating sets, lap times after a lap-number reset, and Stream Recorder reliability.

## New Features

### Search in the Function Browser

The Function Browser now has a search box that filters the function list as you type, matching on function and parameter names. This makes it much quicker to find a function in large libraries, where scrolling was previously the only option.

### Tooltips on Truncated Summary Column Headers

Column headers in the Summary display now show a tooltip with the full header text, so you can read headers that are truncated when a column is narrow.

### Waveform Legend: Strikethrough Visible at Small Font Sizes

The strikethrough used in the Waveform legend to mark hidden items now stays visible at small font sizes. Previously it disappeared below 10pt.

### Waveform Legend: Monospaced Font for Binary Values

Binary values in the Waveform legend are now shown in a monospaced font, so the digits line up and are easier to read and compare.

## Bug Fixes

### Crash and Workbook Corruption When Creating a 23rd Set

Fixed an issue where deleting a set and then creating a new one could assign it set number 23, causing ATLAS to crash and the workbook to become corrupted. Deleted set numbers are now reused, and the number of sets is limited to 22.

### Incorrect Lap Times After a Lap Number Reset

Fixed an issue where the `LapTime` and `CurrentLapNumber` processors could return the wrong lap when the lap number reset during a session, for example when a car is powered off during a red flag. Lap times for laps after a reset now come from the correct lap rather than the earlier lap with the same number.

### Stream Recorder Not Stopping with Two or More Sessions

Fixed an intermittent issue where Stream Recorder would not stop when more than one session was running.

### Stream Recorder Configuration Changes Not Applied in Auto Record

Fixed an issue where changes made to a Stream Recorder configuration were not applied to recorders set to auto record until auto record was switched off and on again. Configuration changes now take effect on those recorders straight away.

### Discrepancies in Virtual Parameter Values for Recorded VPS Sessions

Fixed discrepancies in virtual parameter values seen when comparing a VPS session recorded with Stream Recorder against the original session data.

### Samples Returned Outside the Requested Range for File Sessions

Fixed an issue where sample requests against file sessions could return samples outside the requested range, which could cause a Histogram to show no data for a parameter.
