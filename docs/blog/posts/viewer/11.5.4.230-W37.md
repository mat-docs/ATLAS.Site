# ATLAS Viewer Release: v11.5.4.230-W37

This release adds VPS session recording to Stream Recorder and introduces a new FFT display as a preview feature, alongside fixes for distance-mode freezes, and Stream Recorder reliability.

<!-- more -->

!!! info "Evaluation Build Notice"
    This release is provided as an evaluation build, offering early access to a set of completed fixes and features ahead of a full production release. Evaluation builds are intended for validation and early feedback, and while the included changes are functionally complete, there may still be known limitations or issues that are addressed before the final release. We encourage users to report any problems or feedback encountered during evaluation, as this helps ensure the highest quality for the full release.

## New Features

### VPS Session Recording in Stream Recorder
Stream Recorder can now record Virtual Parameter Service (VPS) sessions as an option, allowing calculated virtual parameters to be captured and viewed in ATLAS — useful for debugging and validating model inputs that are calculated by VPS rather than loaded directly.

### FFT Display (Preview Feature)
ATLAS now includes a new FFT display for frequency-domain analysis, available from File > New > Display when the Preview Features toggle is enabled (Tools > Options > General > Preview Features > "Allow FFT Display (Preview Feature) — restart required"). This first version supports a single parameter per display, giving users analysing vibration, suspension/damper behaviour, aero buffeting, sensor noise, or gear-mesh phenomena a way to view a spectrum without exporting data to external tools.

As a preview feature, the FFT display is still evolving, and your input directly shapes where we take it next. If there's a capability you'd like to see — a specific windowing function, multi-parameter overlay, axis or scaling option, export format, and so on — please raise it as a feature request via the [Portal](https://portal.motionapplied.com/Tickets/New). The more specific you can be about your use case, the better we can prioritise it. We review these requests regularly to guide the display's development ahead of its full release.

## Bug Fixes

### Built-in Memory Profiler Crash
Fixed a crash that occurred when starting the built-in Memory Profiler (Tools > Performance Profilers > Memory).

### ATLAS Freezes in Distance Mode After a Lap Trigger (#7385)
Fixed an issue where ATLAS could freeze in distance mode after a lap trigger, caused by an invalid start/end time range being requested from SQL Race.

### Stream Recorder Not Starting Reliably with Session Identifier Pattern 
Fixed an issue where Stream Recorder would intermittently fail to start recording when using a Session Identifier Pattern for auto-record, even when the identifier from ADS matched the configured pattern.
