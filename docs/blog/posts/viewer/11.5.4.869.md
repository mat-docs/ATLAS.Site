# ATLAS Viewer Release: v11.5.4.869

This is a patch release on top of v11.5.4.769. It fixes an issue where recorders deleted in the Session Browser reappeared after restarting ATLAS. There are no other changes; see the [v11.5.4.769 release notes](11.5.4.769.md) for everything else in this version.

<!-- more -->

## Bug Fixes

### Deleted Recorders Reappear After Restarting ATLAS (#60829, #61021, #61226)

Fixed an issue where a recorder deleted from the Session Browser was not removed from the workbook, so it came back after you saved, restarted ATLAS and reopened the workbook. Deleting a recorder from the Session Browser now always removes it from the workbook, and the deletion is kept once the workbook is saved.

The **Remove unused recorders from Workbook** option now only controls the automatic clean-up of recorders that no set uses. It no longer prevents you from deleting a recorder yourself.

## Known Issues

### Recorder names keep counting up after deletions

New recorders continue numbering from the highest name used, rather than reusing the numbers of deleted recorders.

### Import/Export Configuration

The ATLAS Tools > Import/Export Configurations does not currently export/import Stream recorder configuration.

### Stream Recorder doesn't rename final lap

When using the ATLAS Stream Recorder, the final lap is not automatically renamed to "In Lap" after logging ends and stays as a numbered lap.

### Stream Recorder virtual sessions don't receive Session Details from the Broker

When the ATLAS Stream Recorder is used with VPS and its Session Details are set to come from the Broker, the virtual session does not receive those details, and any session detail wildcards in the session identifier do not resolve. The parent session is not affected. As a workaround, enter the Session Details in the Stream Recorder's manual entry fields instead.

### ATLAS crashes if closed while a session is loading

Closing ATLAS while a session is still loading into a set can cause ATLAS to crash. To avoid this, wait for the session to finish loading before closing ATLAS.
