# Standalone Stream Recorder Release: v1.1.1.227

The first release of the Standalone Stream Recorder, a Windows console application that records live Stream API telemetry from Kafka straight to SSN2 files or a SQL Race database, with no need for ATLAS Viewer to be running.

<!-- more -->

## New Features

### Record Live Telemetry Without ATLAS Viewer

The Standalone Stream Recorder runs as its own process on any Windows machine that can reach your Kafka broker. It connects to the broker, waits for sessions published on the configured data source, records each one as it streams, and then waits for the next. This lets you replace workflows that needed both the ATLAS Stream Recorder and a separate process with a single standalone recorder.

```
Car → ADS → Bridge Service → Kafka → Standalone Stream Recorder → SSN2 / SQL Race database
```

The recorder requires a machine with an ATLAS licence.

### Record to SSN2 Files or a SQL Race Database

Choose the output with `WritingConfig.SessionFormat`:

| Format | Output |
|---|---|
| `SSN2` | One SSN2 file per session, written live to a folder. The folder path supports wildcards, and sessions can optionally be written to a temporary folder first. |
| `Database` | Sessions written live to a SQL Race database (SQLite or SQL Server), which can be loaded live through the recorder's Server Listener. |

Parameter wildcards and other wildcards are supported for both formats. Recording directly to SSN2 is not available in the ATLAS Stream Recorder.

### Choose Which Sessions to Record

Filter sessions with `StreamReadingConfig.SessionIdentifierPattern`, choose whether Virtual Parameter Service sessions are recorded with `RecordVpsSessions`, and set `StreamReadingConfig.GroupId` so the recorder resumes from where it left off after a disconnect. The recorder offers the same settings, with the same behaviour, as the ATLAS Stream Recorder.

### Configuration Validated Before Start-up

All settings live in `Config/AppConfig.json`, which ships with a sample file and a JSON schema describing every option. The recorder checks the whole file before it starts, including combinations of settings (for example, a `Database` format with no connection string), and refuses to start with a clear message naming the problem. Settings can also be overridden with environment variables. Kafka authentication works the same way as in the ATLAS Stream Recorder.

See the [Standalone Stream Recorder documentation](../../../key-functionality/analyse/standalone-stream-recorder/index.md) to get started.
