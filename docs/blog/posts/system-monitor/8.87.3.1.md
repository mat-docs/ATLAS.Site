# System Monitor Release: v8.87.3.1

This release adds support for Enhanced Slow Row on the TAG-700 and resolves three issues affecting remote upload, grid stability, and data version loading performance.

<!-- more -->

## New Features

### CVRR (Enhanced Slow Row) Support on TAG-700

System Monitor now supports CVRR (Enhanced Slow Row) for application parameters on the TAG-700. 

**Please note:** This feature requires a specific supporting BIOS on the TAG-700. It will not be available in SM until the correct BIOS version is in place on the unit.

## Bug Fixes

### Remote Upload Fails With More Than One Buffer Configured on a Bus

Resolved an issue where remote upload could fail to upload the CLC when more than one buffer was configured on any CAN bus.

### Crash When Removing Rows From a Grid

Fixed a crash when removing rows from a grid where the grid shrank down to a row still containing data.

### Performance Delay When Opening a Different DTV Version

Fixed a performance regression where opening a different DTV file version was slow to iterate through multiple PGV folders/versions before resolving the correct PGV.
