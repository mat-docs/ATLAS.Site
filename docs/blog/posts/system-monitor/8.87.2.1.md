# System Monitor Release: v8.87.2.1

System Monitor 8.87.2.1 is a supporting release for CAN FD, which is being enabled in upcoming BIOS versions. It contains no other changes and has no release notes of its own.

<!-- more -->

## Why this release exists

System Monitor will continue to be released with release notes. This release is a special case: it accompanies the equivalent TAG-700 BIOS release for CAN FD, so there are no System Monitor-specific changes to describe.

## Which version should I use?

If you are using BIOS B128 or later, you need to upgrade to System Monitor 8.87.2.1.

**Please note:** If you are on a BIOS version after B128, a CLC file saved with System Monitor 8.87.2.1 cannot be opened by earlier versions, such as 8.86. Check which version you are using before saving or sharing a CLC.
