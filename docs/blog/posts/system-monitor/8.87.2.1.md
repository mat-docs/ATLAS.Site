# System Monitor Release: v8.87.2.1

System Monitor 8.87.2.1 supports CAN FD messages in TAG-700 BIOS Config CAN. CAN FD support in Config CAN was introduced in BIOS B135. System Monitor 8.87.2.1 contains no other changes.

<!-- more -->

## Why this release exists

System Monitor will continue to be released with release notes. This release is a special case: it exists to support CAN FD messages in TAG-700 BIOS Config CAN, introduced in BIOS B135, so there are no other System Monitor-specific changes to describe.

## Which version should I use?

Use System Monitor 8.87.2.1 when configuring CAN FD messages in Config CAN with TAG-700 BIOS B135 or later.

**Please note:** CLC files created or saved with System Monitor 8.87.2.1 cannot be opened with an earlier version of System Monitor. This limitation applies regardless of the BIOS version. Check which System Monitor version you and your team are using before creating, saving, or sharing a CLC.
