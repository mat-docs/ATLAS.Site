# vTAG Server Release: v1.87.1.107

This release fixes two crashes in vTAG Server, one at the end of session reprocessing and one on shutdown.

<!-- more -->

## Bug Fixes

### Crash at the End of Reprocessing (#60790, #60811)

Fixed an issue where vTAG Server could crash at the end of reprocessing a SQL Race or SSN2 session. The crash happened while the application was releasing parameter objects, before the final telemetry was flushed, so the end of the session was lost and the output session was left incomplete. Reprocessing now completes and the session is written in full.

### Crash on Shutdown

Fixed an intermittent crash when closing vTAG Server after a session had finished. The crash happened after the session had closed and the workbook had been saved, so no data was affected, but it left crash dumps and an error message on exit.
